## 4. 디자인 (Q50·Q83)

- 요구: "최신 UI/UX 트렌드를 찾아서 구현". **공개 사이트 단계 직전(M6)** 에 트렌드 조사 문서 `docs/research/ui-trends.md`(참고 사이트, 레이아웃·타이포·색·모션·지도 UI·데이터 시각화 패턴, 적용 여부 판단)를 만들고 시안 → 디자인 토큰 확정 → `packages/ui` 반영(관리 앱도 토큰 교체). (Q83 A)
- 고정 조건: 노선 색은 주요 시각 요소이되 색만으로 정보를 전달하지 않는다, 출처·검수 상태가 늘 보인다, 비상업(광고 영역 없음), 지도 노선 색 규칙(수도권 전철 노선만 공식 색, 나머지 상태 대표색) 승계.
- 상세 정보(동호인용)는 접힘 절. 웹 글꼴은 자가 호스팅만(외부 CDN 없음).

화면 골격(시안 기준):

- **상세 페이지** = 머리 띠(노선 색 6px 띠 — 역은 지나는 노선 색 줄무늬, 계획은 단계 색) → 이동 경로 → 이름(한국어 주, 영문·주소 아래 줄) → 배지 줄(상태·분류·**검수**) → 핵심 수치 칸(값 + 작은 출처 각주) → 고정 절 탐색(앵커 유지) → 본문 + 옆 패널(약도·지도 바로가기·관련 항목·"이 페이지" 검수·확인일). 출처 절은 번호 목록(발행처·유형·라이선스·받은 날·대상 필드).
- **계획 상세** = 12칸 단계 진행 띠(번호·이름·도달 연도, 현재 칸 `aria-current="step"`, 개통 예정 칸은 빗금) + 기대 일정 상자(근거·발표 시점·"바뀔 수 있음") + 단계 이력 타임라인(항목마다 단계 배지·출처·출처 유형).
- **미래 지도** = 전체 화면 지도 + 왼쪽 패널 384px(좁은 화면은 아래 시트) + 지도 아래 연도 띠(연도별 변화량 막대, ‹ › 버튼·←/→ 키로 끌기 대안) + 계획 정보 창. 패널 안 "새로 생기는 노선" 목록이 지도 대체 정보(FR-WEB-026).
- 상태·단계·검수 배지는 색 + 모양(●◐○‖✕—, 실선/점선) + 글자. 노선 칩은 노선 색 바탕 + 대비 큰 글자색(`readableOn`), 공식 색이 없으면 점선 칩.
- 날짜 정밀도가 일 단위일 때만 D-day 배지(월·반기·연 단위는 기간 그대로).
