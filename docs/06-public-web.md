## 3. 지도·미래 지도 (Q87~Q93, 2026-11-20 추가 요구)

| ID | 요구사항 |
| --- | --- |
| FR-WEB-020 | `/map/` 에 **현재 / 미래** 전환과 **연도 슬라이더**(현재 연도 ~ 가장 늦은 개통 예정 연도 + "목표 미정")를 둔다. URL `?at=2030`(또는 `at=future`), 기존 `#line= #station= #plan=` 강조와 함께 동작. 헤더·홈에 "미래 지도" 바로가기(`/map/?at=future`). (Q87 A) |
| FR-WEB-021 | 선택한 연도의 노선도 = 03 문서 6-1절 규칙: 그때까지 개통 예정인 계획·공사 중 노선을 더하고, 대체(replaces)되는 노선·폐역 예정 역은 숨기며, 연장(extends)은 기존 노선 색으로 이어 그린다. (Q90 A) |
| FR-WEB-022 | 포함 범위: 기본 = **기대 일정(개통 예정)이 있는 계획** + 공사 중 노선. 단계 필터(기본계획 이상 / 예비타당성 이상 / 전체)로 조절. 휴면·폐기 제외. (Q88) |
| FR-WEB-023 | 선 모양 = 단계(시공 실선 / 설계 굵은 점선 / 그 전 가는 점선). 색 = 연장이면 기존 노선색, 공식 노선색(출처 있음)이면 그 색, 아니면 단계 대표색 + 계획 이름 라벨. (Q91 A) |
| FR-WEB-024 | 선형 품질 표시: OSM 공사 선형·도면 추출 선형은 그대로, 경유역 개략 선형은 부드러운 곡선 + 가는 점선 + 범례 "선형 미확정(개략)". (Q89 A) |
| FR-WEB-025 | 개통 목표 미정 계획은 슬라이더 끝 "목표 미정" 칸에서만, 목표가 지난 미개통은 현재 연도에 "지연" 배지. 계획 클릭 → 패널: 이름·단계·개통 예정(근거·발표 시점)·지연 여부·계획 상세 링크. (Q92 A) |
| FR-WEB-026 | 지도 아래(또는 옆) 목록: 선택 연도에 새로 생기는 노선·역, 사라지는 노선·역. 지도 없이도 정보 접근(접근성). |
| FR-WEB-027 | 고지문: "개통 예정은 발표 시점 기준이며 바뀔 수 있음, 개략 선형은 실제 위치와 다를 수 있음". 지리 지도만 제공(도식 노선도는 후보, Q93 A). |
| FR-WEB-028 | 배경: VWorld(기존 결정). 구글 지도는 공개 사이트에 쓰지 않는다(관리 앱 위성 비교 전용, Q68 A). |

## 4. 디자인 (Q50·Q83)

- 요구: "최신 UI/UX 트렌드를 찾아서 구현". **공개 사이트 단계 직전(M6)** 에 트렌드 조사 문서 `docs/research/ui-trends.md`(참고 사이트, 레이아웃·타이포·색·모션·지도 UI·데이터 시각화 패턴, 적용 여부 판단)를 만들고 시안 → 디자인 토큰 확정 → `packages/ui` 반영(관리 앱도 토큰 교체). (Q83 A)
- 고정 조건: 노선 색은 주요 시각 요소이되 색만으로 정보를 전달하지 않는다, 출처·검수 상태가 늘 보인다, 비상업(광고 영역 없음), 지도 노선 색 규칙(수도권 전철 노선만 공식 색, 나머지 상태 대표색) 승계.
- 상세 정보(동호인용)는 접힘 절. 웹 글꼴은 자가 호스팅만(외부 CDN 없음).
