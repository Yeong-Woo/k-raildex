# 품질 목록 검수 안내 (관리 앱)

관리 앱 → **품질**(`/quality`)에서 규칙을 고르면 대상 행이 나온다. 행의 id 를 누르면 그 개체 편집 화면(`/data/<유형>/<id>`)이 열린다.
편집 화면에서 값을 고치고 **저장** → 확인 창에서 **저장**을 누르면 변경 묶음으로 기록되고 바로 반영된다(이력은 **변경 묶음** 메뉴).
고친 행은 규칙 조건에서 벗어나면 목록에서 저절로 빠진다(숫자는 새로 고치면 줄어든다).

공통 원칙(CLAUDE.md 3절)

- 값을 고칠 때는 **출처**(출처 탭)와 **확인일**을 함께. 확인 못 한 값은 비워 둔다(추측 금지).
- 출처 우선순위: 법령·고시 > 국토교통부·국가철도공단·운영기관 > 언론 > 위키(보조).
- 별개라고 확인한 것 등 "고칠 것 없음" 판정은 **편집 메모(editor_note)** 에 근거를 적는다 — 일부 규칙은 메모로 목록에서 빠진다.

## 1. round-06 에서 직접 검수하기로 한 것

### X-plan-line-role — 계획 노선 역할 확인 (약 150건, Q120)

- 무엇: 이관 때 계획에 걸린 운영 중 노선을 기계적으로 "개량(upgrades)"으로 묶었다. 실제로는 개량 대상이 아니라 "새 계통이 지나는 기존 노선"인 경우가 섞여 있다.
- 행: 계획 id + `노선 id — 노선 이름`.
- 검수: 계획 편집 → **노선** 표에서 그 노선의 역할을 본다.
  - 실제로 선로를 고치는 사업(복선화·전철화·직선화·고속화)이면 **역할 그대로 두고 메모(note)** 에 무엇을 하는지(예 "전의~전동 직선화 4km") 적는다.
  - 새 노선을 짓는 사업이면 `new`, 기존 노선을 늘리는 사업이면 `extends` 로 바꾼다.
  - 고치지 않고 새 계통 열차가 기존 선로를 함께 쓰기만 하는 노선(예: GTX-B 가 망우~마석에서 쓰는 경춘선, 수원발 KTX 가 지나는 경부선)이면 역할을 **`shares`(선로 공용)** 로 바꾼다. 어느 구간인지 메모에 적으면 더 좋다(예 "망우~마석").
- 빠지는 조건: 역할이 upgrades 가 아니거나, 메모가 적혀 있으면.
- 지도 영향: new·extends 노선은 미래 지도에 계획 선으로 그려진다. upgrades·shares 는 그리지 않는다(계획 상세에 역할로만 보인다).

### X-station-near-other-name — 150m 안의 이름이 다른 역 (5쌍, Q122)

- 무엇: 옛 이름으로 남은 중복 역이거나 근사 좌표일 수 있다(예: 인천국제공항 ↔ 인천공항1터미널, 발산 ↔ 마곡, 이촌 ↔ 신용산).
- 행: 역 A id + `역 B id 이름 와 거리m`.
- 검수:
  - **같은 역**(이름만 바뀐 것): 남길 역을 정해 메모로 알려 주면 병합한다(옛 역의 노선별 역·시간표를 옮기고 삭제 + 옛 주소 이동 id_redirect — 북창원 → 창원중앙 때와 같은 방식). `merge_into_id` 필드는 "공사 중 분리 정거장"용이라 쓰지 않는다.
  - **다른 역**(환승 통로로 이어진 별개 역 등): 한쪽 역의 편집 메모에 상대 id 를 적는다 — 예 `별개 역 확인: stn-magok`.
  - **좌표가 틀림**: 좌표를 고치고 좌표 출처·근거(coord_basis)를 맞춘다.
- 빠지는 조건: 삭제, 좌표가 150m 밖으로, 또는 어느 한쪽 메모에 상대 id.

### X-operator-merge-source — 운영기관 통합의 1차 출처 (1건, Q123)

- 무엇: SR 을 `merged`(승계 코레일, 2026-09-01)로 처리했는데 법령·고시·공고 출처가 없다.
- 검수: 1차 출처(법령 개정, 국토부 고시·공고, 공정위 결합 승인 공고 등)를 **출처**로 새로 만들고(유형 `법령` 또는 `고시·공고`), 운영기관 편집 → 출처 탭에서 그 출처를 **필드 `merged_into_id`** 에 연결한다.
- 빠지는 조건: `merged_into_id` 필드에 법령·고시 유형 출처가 붙으면.

### X-station-no-coord — 노선에 속했는데 좌표 없는 역 (33곳, Q124)

- 무엇: 운영 중 시설(신호장 등) 19·폐역 8·공사 중 6곳. (운영 중 여객역은 이미 0 — V-S02)
- 행: 역 id + `상태 · 종류 · 노선`.
- 검수: 역 편집 → 좌표(위도·경도) 입력. 공식 위치를 모르면 근사 좌표로 넣고 **좌표 근거(coord_basis)** 를 `parcel`(지번)·`district`(읍면동)·`township` 중 맞는 것으로 둔다 — 지도는 근사 좌표를 노선 선형에 붙여 그린다. 구글 지도 좌표는 쓰지 않는다(Q68).
  - **지도 편집**(`/map`)이 더 빠르다: 왼쪽 "좌표 없는 역" 목록(V-S02 + 이 규칙)에서 역을 고르면 찍기 모드가 켜진다.
    - 지도를 클릭(또는 표식을 끌어) → 좌표 저장 = 좌표 출처 "수기 확인".
    - **[다른 역 좌표 쓰기]** → 지도의 역 점을 클릭하거나 칸에서 역을 찾음 → 저장 = 그 역 좌표로 덮어쓰기(좌표 출처 "추정", 근거 "기존 역 좌표", `coord_same_as_id` = 그 역). 같은 자리의 운영 중 역이 있는 신호장·폐역·공사 중 정거장에 쓴다.
- 빠지는 조건: 좌표 또는 coord_same_as_id 가 생기면.
