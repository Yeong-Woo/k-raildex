## A. 계획·노선

- 배경: `plan-cheoldojonghapsiheomseon-osong-cheoldojonghapsiheomseollo` 는 개통(2023-08 준공 고시 제2023-487호) 단계인데 이어진 노선이 없다(X-plan-no-line 남은 1건). 사업용 철도 노선번호가 없는 시험 선로다.
- 선택지: A 노선을 만들지 않음(계획 내부 메모 "노선 연결 안 함: 시험 선로") / B 시설(facility)로 등록 / C 노선으로 만듦(여객 미취급)

- 영향: 시설 종류 코드(facilityKind), 계획 노선 연결

### Q142. 계획 노선 역할(이관 upgrades, 130건)을 어떤 기준으로 바로잡을까? ★

- 배경: 이관 때 운영 중 노선에 잇는 계획을 모두 upgrades(개량, 지도에 안 그림)로 넣었다. 남은 130건에는 연장(신분당선 광교~호매실, 별내선 연장, 일산선 연장), 선로 공용(GTX-B 경춘선, GTX-C 경원선·과천선·안산선·경부선), 환승 지점일 뿐인 노선(대장홍대선의 경의선·2호선, 송파하남선의 3·5호선)이 섞여 있다.
- 선택지:
  - A 규칙으로 일괄: 계획 이름·설명에 "연장"이고 그 노선의 연장이면 extends / 새 노선이 기존 선로를 함께 쓰면 shares / 환승만 하는 노선은 역할 줄을 지움(plan_station 의 existing 역으로 충분) — 결과 목록을 보고 승인
  - B 계획마다 사람이 정함
  - C 지금대로(upgrades)
- 추천: **A** — 대부분 이름·설명으로 판단되고, 애매한 것만 B 로 남긴다.
- 영향: 미래 지도(연장 구간이 노선 색으로 그려짐), 노선 페이지 관련 계획
- 답변:
