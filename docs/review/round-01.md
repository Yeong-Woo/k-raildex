## C. 데이터 모델

### Q15. ★ 저장 방식 — 정규화 vs 문서형(jsonb)?

- 배경: 기존 DB 는 개체마다 `data jsonb` + 일부 열. 관계 무결성을 검증 스크립트가 맡았다.
- 선택지: A. 정규화 관계형(관계·조회 필드는 테이블·열, `extra jsonb` 는 예외용) / B. 기존처럼 jsonb 문서 + 조회 열 / C. 하이브리드(핵심 개체 정규화, 계획·환승센터 같은 중첩 많은 개체는 jsonb)
- 추천: **A** — 관리 앱의 관계 편집·참조 검사·삭제 거부·병합을 DB 가 보장. 03 문서는 A 기준.

- 답변: A

- 추천: **A** — URL 안정·이관 단순. 접두사 겹침은 실제 충돌이 없으면 그대로 둔다(전역 유일만 보장되면 문제없음).
