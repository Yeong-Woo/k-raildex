# Round 08 OSM 전국 대조 — 역·시설·노선 누락 후보

- 작성일: 2026-11-28. Overpass 로 대한민국 철도 노드(railway=station·halt·yard·junction·service_station, public_transport=station 중 train·subway·light_rail) 1,588개의 **태그(이름)만** 받아 DB 역 그룹·별칭·시설 이름과 대조했다(좌표는 받지 않음·저장하지 않음, C-5). 노선은 이미 적재한 `osm.relation`(route=tracks·subway·light_rail·train) 중 어느 노선에도 배정되지 않은 것을 뽑았다.
