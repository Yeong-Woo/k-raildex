### Q99. "이용허락범위 제한 없음" 데이터셋의 라이선스 구분은?
- 배경: 출처 625건 중 129건이 `unknown` 이고 대부분 공공데이터포털의 "이용허락범위 제한 없음" 데이터셋이다. 구분은 원문 공개 다운로드 판정에 쓰인다(Q75). "공공누리 제1유형 추정·에 준함" 처럼 유보 표현이 붙은 것도 unknown 으로 뒀다.
- 선택지: A. "이용허락범위 제한 없음" → `open`(공개 가능), 유보 표현은 unknown 유지 / B. 전부 unknown 유지(관리 앱에서 하나씩 판정) / C. `kogl_1` 로 간주

### Q101. 인천 계획 4건 — 기존 단계는 "폐기"인데 단계 이력에 폐기 근거가 없다. 어떻게 할까?
- 배경: 현재 단계는 단계 이력에서 계산한다(Q28 A). 기존 데이터는 4건을 `abandoned` 로 두었지만 이력에 폐기 항목(날짜·출처)이 없어 계산 결과가 `plan_listed` 가 된다.
- 선택지: A. 기존 레코드의 출처·설명에서 폐기 근거를 찾아 단계 이력에 추가(찾을 때까지 `stage_override = abandoned` 로 임시 유지) / B. 근거가 없으니 `plan_listed` 로 둔다(현재 계산값) / C. `dormant`(휴면)로 둔다
- 추천: **A** — 기존 판단을 잃지 않되, 근거가 확인되면 override 를 걷어 낸다.

- 추천: **A** — 확인 안 된 사실을 쓰지 않는다(C-1). 확인되면 B.
