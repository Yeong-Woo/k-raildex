### Q127. 색이 없는 운행 계통을 지도에서 강조할 때 색은?

- 배경: 운행 계통 92개 중 24개만 `color` 가 있다. 색이 없으면 강조선이 노란색(#F5B700)이다.
- 선택지: A 계통의 첫 노선(대표 노선) 색을 따른다(계산, 저장 안 함) / B 계통마다 색을 데이터로 넣는다 / C 노란색 그대로
- 추천: **A** — 데이터 손 안 대고 대부분 노선도와 맞는 색이 된다. 공식 색이 다른 계통만 B 로 넣는다.
- 영향: 03 문서 6-2절, 공개 지도 운행 계통 응답
- 답변: A

### Q128. 겹친 노선의 관계(공용 구간·병행·지하 통과)를 표시할까? ★

- 배경: 서대구역처럼 경부고속선이 지하로 통과하고 지상에 경부선 역이 있는 경우 지도에서 구분이 안 된다(notes.md round-06 후보).
- 선택지: A OSM 에서 계산(같은 way = 공용 구간, 다른 way 나란히 = 병행, tunnel·bridge·layer 다르면 입체 분리)해 지도 터널 구간은 옅은 점선, 노선 정보·고르기 목록에 표시. 역 승강장 층은 노선별 역 속성 `structure` 로 큐레이션(출처 필요) / B 지도 터널 점선만 / C 미룬다
- 추천: **A** — OSM 값은 저장하지 않고 계산만 해 C-5 를 지킨다.
- 영향: 03 문서(line_station.structure), 지도 층, 공개 API
- 답변: A
