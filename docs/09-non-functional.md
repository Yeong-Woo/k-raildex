## 2. 보안

## 8. CI/CD

```
PR: lint(eslint, prettier) → typecheck → unit → integration(Testcontainers) → build(web·admin·api·worker) → gitleaks
main: + 이미지 빌드(GHCR) → (수동 승인) 서버에서 compose pull·up, DB 마이그레이션 먼저
야간: 이관 리허설·대조 리포트(컷오버 전까지)
```

- DB 마이그레이션은 앞으로 호환(expand → migrate → contract) 원칙, 배포 전 자동 백업.
- 저장소 공개: 관리 앱 완성(M5) 후(Q66 B). 공개 전 gitleaks 전체 이력 검사.
