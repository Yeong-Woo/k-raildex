- 조사일: 2026-10-11
- 조사 방법: WebSearch로 후보를 찾은 뒤, 공공데이터포털(data.go.kr)·서울 열린데이터광장·레일포털(KRIC)·국가철도공단·국가법령정보센터 Open API(law.go.kr/DRF)·국가교통DB 페이지를 직접 열어 확인. 국토교통부(molit.go.kr) 페이지는 접속 시 무한 리다이렉트로 직접 열람 실패(아래 "미열람"으로 표기). URL 목록은 실제로 연 것만 적음.

#### RAFIS 표기 규칙 (2026-10-12 확인, src-kric-rafis-station 원문 692행 대조)

RAFIS 역 정보 CSV(CP949)에는 노선 열이 없지만 **행이 노선별로 묶여 순서대로 놓여 있다**(예: 행 671~676 = 수서평택고속선 S수서 0 → S성남 10.2 → S구성 21.2 → S동탄 32.6 → 평택지제 53.6 → SR분기 61.1, 기준역간KP 단조 증가). 아래 규칙은 이 행 묶음·KP·영문·한자·등록일을 표준데이터·코레일 역키로정내역과 대조해 확인한 **관찰 결과**이며, 공단의 공식 표기 지침은 찾지 못했다(미확인 — 문의 후보).

|---|---|---|
| 숫자 접두 `1` | 같은 이름이 이미 있는 역의 다른 노선 등록 | 1양정(중앙선 묶음 KP 14.9, 키로정 "양정역" 20149) = 경의·중앙선 양정 / 1양원(KP 6.3, 키로정 "양원역" 20063) = 경의·중앙선 양원 / 1평택지제(경부선 묶음 KP 71.3) = 경부선 평택지제 |

## 5. 라이선스 정리

- 공공누리(KOGL) 유형 (출처: https://www.copyright.or.kr/gov/nuri/rule_info/index.do, https://www.kogl.or.kr/info/license.do)
  - 제0유형: 출처표시 불필요, 상업적 이용·2차 저작물 가능
  - **제1유형(출처표시)**: 출처 표시하면 상업적 이용·변형(2차 저작물) 모두 가능 → 공개 저장소 재배포·가공 가능
  - 제2유형(출처표시+상업적 이용금지): 비영리만, 변형 가능
  - 제3유형(출처표시+변경금지): 상업적 가능, 변형·2차 저작물 금지
  - 제4유형(출처표시+상업적 이용금지+변경금지): 가장 제한
  - AI유형: AI 학습용 한정
  - 출처표시 예시 문구: "본 저작물은 'OOO(기관명)'에서 'OO년' 작성하여 공공누리 제O유형으로 개방한 'OOO(저작물명)'을 이용하였으며, 해당 저작물은 'OOO(기관명), OOO(홈페이지 주소)'에서 무료로 다운받으실 수 있습니다." 링크 제공 가능 시 링크 포함. 기관이 후원·특수관계로 오인되게 표시 금지. 조건 위반 시 이용허락 자동 종료.
- 공공데이터포털 정책(https://www.data.go.kr/ugs/selectPortalPolicyView.do): "저작물이 포함된 공공데이터를 제공하는 경우에는 저작권법 등 관련 법령에 따른 공공누리 유형을 부착", "저작권 등 제3자 권리가 포함된 공공데이터는 권리자의 정당한 이용허락을 확보", 공공데이터 관리지침 제8조③ "이용자가 별도의 이용허락 없이 자유롭게 이용할 수 있도록 제공".
- 각 데이터셋의 유형:
  - data.go.kr의 코레일·국가철도공단·국토교통부·SR·대구교통공사 등 대부분 데이터셋: 상세 페이지에 **"이용허락범위: 제한 없음"**, 비용 무료, 공공누리 유형 번호 **미표기**. "제한 없음"의 공식 정의 문구는 포털 이용안내에서 확인하지 못함(미확인). 실무적으로는 별도 이용허락 없이 자유이용 가능한 데이터로 취급되나, 안전하게 **공공누리 제1유형에 준해 출처(기관명·데이터셋명·URL·기준일)를 표시**하고 재배포하는 것을 권장.
  - 서울 열린데이터광장(서울교통공사 시간표 OA-101/108/109/110, 역명다국어표기 OA-2751, 역간거리 OA-12034, 서울시 역사마스터 OA-21232): **공공누리 제1유형** 명시 → 출처표시 후 재배포·가공 가능.
  - 법령·고시(철도거리표, 명칭관리지침, 각종 고시문): 저작권법상 보호 대상이 아닌 공공 자료로 자유 이용 가능(법령 원문 기준, 본 조사에서는 조문 미확인).
  - KRIC 철도통계연보·레일포털: "All rights reserved" 표기, 공공누리 미표기 → 재배포 전 이용약관 확인 또는 data.go.kr 등록본(이용허락 제한 없음) 사용 권장.
  - 국가교통DB(KTDB): 약관상 무단 복제·배포 금지, 상업적 이용 불가 → **재배포 불가**.
  - 인천시 외국어 페이지 등 일부 지자체 콘텐츠: 공공누리 제4유형(출처표시·상업금지·변경금지) → 데이터 재배포 불가(해당 페이지 자체는 계획 데이터 출처로 부적합).

## 6. 공백(찾지 못한 데이터)과 대안

1. **전국 일반철도 전 역 좌표**: 좌표 있는 공식 데이터는 국가철도공단 철도역 정보(215역)·코레일 역 위치(202역)뿐. 대안: RAFIS 692역의 기준역간KP + 철도거리표로 노선상 위치 추정, 도시철도 표준데이터(1,073역) 좌표와 병합, 나머지는 수기(지도 확인).
2. **노선 선형(GIS)**: 국가공간정보포털·국토지리정보원 수치지도(1/5,000 shape) 존재는 검색으로만 확인, 직접 열람 못함(미확인). KTDB 교통망 GIS는 재배포 불가. 대안: 역 좌표를 잇는 단순 선형 또는 OSM(ODbL, 별도 라이선스 주의). → docs/research/map-and-geometry.md 참조
3. **일반철도(코레일·SR) 전 열차 계획 시간표 파일**: 포털에 정적 전체 파일 없음. 대안: TAGO 열차정보 API(출발·도착역 쌍 조회)와 코레일 열차운행정보 API(운행계획)를 주기적으로 호출해 스냅샷 저장. 코레일 홈페이지 시간표 PDF 존재 여부 미확인.
4. **열차 운행 계통(열차번호→정차역 순서)**: 코레일 열차운행정보 API의 "운행정보"(역별 정차구분)로 복원 가능하나 보존기간 짧음. TAGO는 구간 조회형이라 전체 복원에 많은 호출 필요.
5. **국가철도망 구축계획 고시 원문·고시번호(제4차)**: 미확인. 대안: KRIC 관보 목록 엑셀에서 2021년 7월 전후 검색, 국가철도공단 참고자료(신규사업 현황) 사용.
6. **제5차 국가철도망·제5차 광역교통시행계획**: 미확정(2026-10 기준). 확정 후 수집.
7. **도시철도망 구축계획 고시문(부산·인천·대전·대구·광주)**: 보도만 확인. 대안: 각 시 고시·공고 게시판, 대광위 사이트(접속 실패) 재시도.
8. **철도거리표 최신본**: law.go.kr 현행본이 2015년 고시로 표시. 이후 개정분 수집 경로(관보) 미확인.
9. **폐선 노선 목록(노선 단위)**: 공식 구조화 데이터 없음. 대안: 철도거리표 개정 전/후 비교, 철도통합연표, RAFIS 역폐지일자, 위키는 보조.
10. **노선 영문명 공식 데이터**: 없음. 명칭관리지침 원칙 + 운영기관 노선도로 수기.
11. **KRIC 철도통계 역별 승하차**: 역별 자료 존재 여부 미확인(총괄지표만 확인).
12. **"이용허락범위 제한 없음"의 공식 정의**: 포털 안내 페이지가 JS 렌더링이라 미확인.

## 6-1. API 키 체계 (2026-10-11 추가 확인)
- 공공데이터포털 **파일데이터**: 키 없음. 로그인 없이 다운로드(국가철도공단 RAFIS·철도역 정보·표준데이터·노선정보, 코레일 파일 전부).

- 공공데이터포털 **LINK형**(국가철도공단 열차별운행시각표 15041665, 역사별 운행시각표 15041674 등): 포털에는 메타데이터만 있고 호출 주소는 `https://openapi.kric.go.kr/openapi/{service}/{operation}?serviceKey=...`. 서비스키는 **레일포털(data.kric.go.kr) 각 API 페이지의 "활용신청"** → 본인인증 → 영업일 익일까지 이메일 발급(레일포털 공지 "Open API 활용신청 방법", 2026-07-03, https://data.kric.go.kr/rips/M_04_01/detail.do?id=398). 이용허락범위 "저작권표시".
- 요청 변수 예(열차별 운행시각표): `railOprIsttCd`(운영기관 S1/KR 등), `lnCd`(선 코드), `stinCd`(역 코드), `dayCd`(7 토, 8 평일, 9 휴일), `format`(xml/json).
