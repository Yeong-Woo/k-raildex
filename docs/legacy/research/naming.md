# 프로젝트 이름 후보

- 작성일: 2026-10-11
- 배경: D13에서 "future-rail-db" 변경 결정. 이유: 현재 정보까지 다루므로 "future"가 범위를 좁게 보이게 하고, 미래철도DB와 혼동 우려.
- 기준: (1) 현재 + 계획을 모두 포괄 (2) 미래철도DB·미래철도20XX·noseon.do와 구별 (3) 한국어 서비스명 + 영문 저장소명 쌍 (4) 도메인 확보 가능성(확인 필요)

| 후보 (한국어 / 영문)        | 뜻                      | 장점                                           | 단점                                                          |
| --------------------------- | ----------------------- | ---------------------------------------------- | ------------------------------------------------------------- |
| 철도도감 / raildex          | 철도 백과·도감          | 현재·계획·용어를 모두 담는 "도감" 이미지. 짧음 | "도감"이 가벼운 느낌일 수 있음                                |S
| 한국철도지도 / korail-atlas | 지도·아틀라스           | 지도 탭 강조, 전국 범위 명확                   | korail은 코레일 상표와 충돌 → `k-rail-atlas` 등으로 조정 필요 |
| 철도연표 / railtimeline     | 과거·현재·미래 타임라인 | 이벤트 모델과 일치                             | 시간표(timetable)와 혼동                                      |
| 선로 / seonro               | 선로(線路) 한 단어      | 짧고 기억 쉬움                                 | noseon.do와 어감 유사                                         |
| 철도계획도 / railplan-kr    | 계획 중심               | 궁극 목표(D3) 강조                             | 현재 정보가 가려짐                                            |
| 레일맵코리아 / railmap-kr   | 노선도 중심             | 직관적                                         | 흔한 이름, 상표 검색 필요                                     |

- 1차 추천: **철도도감 (raildex)**. 현재·계획·용어·폐선까지 한 "도감"에 담는다는 컨셉과 가장 잘 맞고, 기존 세 사이트와 겹치지 않는다.
- 2차 추천: **한국철도지도 (k-rail-atlas)**. 지도 탭을 핵심으로 키울 경우.
- 결정 질문은 docs/REFERENCE.md Q14로 등록.
