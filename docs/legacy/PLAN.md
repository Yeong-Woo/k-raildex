## 2. 데이터 모델 (요약)

상세는 docs/research/tech-stack.md 4절. Phase 0에서 JSON Schema로 확정한다.

```
Operator ─┐
Line(물리 노선) ── Section(구간, 상태·개통일·폐지일) ── Station(역, 좌표, 상태, 외부 코드)
   │                                                    │
   └── LineStation(순서·km·승강장)                       └── Transfer(환승 관계)
Service(운행 계통) ── ServiceStop(정차 패턴) ── Timetable(계획 시간표, 정적)
Plan(계획 사업) ── PlanStage(단계 이력) ── PlanRef(상위 계획 반영: 4차 신규/추가검토 등)
Event(개통·폐지·역명변경·환승개시·단계변경, 날짜 정밀도) ── 모든 개체 참조
Source(출처: 고시번호·URL·발행일·확인일·라이선스) ── 모든 사실 필드가 참조
Geometry(LineString, 출처·정확도 등급) ── Line 또는 Plan
```

상태값: `operating` / `planned(stage)` / `under_construction` / `abandoned`(폐기) / `closed`(폐선·폐역).

## 2-1. 우선 범위 (D18, 2026-10-11)

데이터 수집은 전국(D1)이지만, **수기 입력·검수·지도·계획·시간표 작업은 아래 순서**로 한다.

| 순위 | 범위                 | 포함                                                                                                                                                                                                       |
| ---- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 고속철도             | 고속선 전부(경부·호남·수서평택·경강·중앙 준고속 등), KTX·SRT 정차역(지방 주요역 포함)                                                                                                                      |
| 1    | 수도권 전철·광역전철 | 서울교통공사·코레일 광역전철·민자(신분당·공항철도)·경전철·GTX-A 전 노선, 이들이 지나는 간선(경부선 서울~천안, 경인선, 경의선, 경원선, 경춘선, 중앙선, 안산선, 과천선, 분당선, 일산선, 수인선, 장항선 일부) |
| 2    | 지방 도시철도        | 부산·대구·대전·광주·인천 외 지역 — 자동 수집 데이터는 유지, 사이트에 "검수 전" 표시                                                                                                                        |
| 3    | 지방 일반철도 간선   | 전라선·경전선·동해선·중앙선 남부 등                                                                                                                                                                        |

Phase 2(지도 선형), Phase 3(계획 정보), Phase 4(시간표)도 1순위 범위부터 채운다.
