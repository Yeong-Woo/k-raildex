# Concept

- 열차, 철도에 관한 정보를 제공하는 웹페이지를 만들고 싶어.
- 도시철도, 일반철도, 광역철도, 고속철도 등 용어에 대한 정의와 열차 정보, 노선도, 운행 계통 등 현재 존재하는 정보를 제공하고 싶어.
- 국토종합계획, 국가철도망구축계획에 기반한 노선의 개발 계획과 현재 상태, 그리고 최신 정보를 제공하고 싶어.

# 조사 메모 (2026-10-11)

- API 키 체계(2026-10-11 확인): 국가철도공단 데이터는 두 종류다. (1) 파일데이터(역 정보, 표준데이터, 노선정보)는 공공데이터포털에서 키 없이 다운로드. (2) 도시철도 Open API(열차별·역사별 운행시각표 등 60종)는 공공데이터포털에 LINK형으로만 등록되어 있고 실제 호출 주소는 openapi.kric.go.kr, 서비스키는 레일포털에서 서비스별 활용신청 후 이메일 발급(레일포털 공지 2026-07-03). 공공데이터포털 자체 API(TAGO, 코레일 열차운행정보 등)는 서비스별 활용신청이 필요하다. 개인 계정의 인증키가 계정당 하나인지는 공식 FAQ 원문을 찾지 못해 `미확인`. .env는 공통 키 + 서비스별 개별 키 둘 다 받도록 설계했다.

- 제5차 국가철도망 구축계획(2026~2035): 2026-10-11 기준 **확정·고시 전**. 당초 2025년 6월 발표 예정이었으나 1년 이상 지연. 2026년 하반기 공청회·심의 후 연내 확정 예정으로 보도됨. 확정되면 "계획 정보"의 기준 문서가 바뀌므로 추적 필요.
- 법령 정의: 고속철도·일반철도는 「철도의 건설 및 철도시설 유지관리에 관한 법률」, 도시철도는 「도시철도법」, 광역철도는 「대도시권 광역교통 관리에 관한 특별법」. 현행 조문은 국가법령정보센터(law.go.kr)에서 원문 재확인 필요.
- 데이터 출처 후보 (상세 조사 예정, docs/research/ 에 기록)
  - 국토교통부 보도자료·고시(국가철도망 구축계획, 기본계획 고시)
  - 국가철도공단: 사업 현황, 철도거리표
  - 공공데이터포털(data.go.kr): 코레일 역·노선·열차 정보 API, 국토교통부 TAGO 열차 정보 API
  - 서울 열린데이터광장, 각 지방 도시철도 운영기관 공개 데이터
  - 국가법령정보센터: 법령·고시 원문
  - 지도: 국토지리정보원 / VWorld / OpenStreetMap(철도 선형 데이터) — 라이선스 확인 필요

## 결정에서 파생되는 원칙

- D3: Phase 1은 "현재 노선·역·운행 계통"을 전국 단위로 갖추는 것. 계획 정보는 데이터 모델에 처음부터 자리를 두되 입력은 이후 Phase.
- D5+D9: 데이터의 원본(source of truth)은 git 저장소 안의 구조화 파일. API는 초기 적재와 주기적 대조용.
- D6+D9: 실시간·사용자 계정·편집 UI가 없으므로 서버 상주 백엔드의 필요성은 낮다. D8 결정은 기술 조사 결과(docs/research/tech-stack.md)로 판단.
- D7: 노선도는 (1) 운영기관 공개 노선도 이미지/PDF 링크·임베드 → (2) 지도 탭(지도 라이브러리 + 선형 데이터) 순서.
- D11: 개체 상태값에 `운영중 / 계획(단계별) / 폐기 / 폐선 / 폐역`을 둔다.
- D14: 문서·UI에서 서비스 이름은 "한국철도도감", 영문 "K-Raildex". 저장소 이름 변경(P1)과 함께 CLAUDE.md·PLAN.md 반영.
- D16: VWorld 키는 환경 변수(VWORLD_API_KEY)로만 다루고 저장소에 커밋하지 않는다. 포크한 사람은 자기 키를 발급한다. VWorld 장애·정책 변경에 대비해 지도 컴포넌트는 타일 소스를 설정으로 바꿀 수 있게 만든다.
- D18: 일반철도 물리 노선(round-1 Q18)은 우선 범위에 해당하는 고속선과 수도권 전철이 지나는 간선(경부선 서울~천안, 경인선, 경의선, 경원선, 경춘선, 중앙선, 안산선, 과천선, 분당선, 일산선, 수인선, 장항선 일부) 약 15~20개를 먼저 입력한다. 레코드에 `review_status`(verified / auto) 같은 검수 상태를 두어 사이트에서 "검수 전"을 표시한다(필드 설계는 round-2).
- D17: 비상업 원칙을 CLAUDE.md에 명시. 광고·후원 결제·유료 기능을 넣으려면 코레일 노선도 게시를 먼저 철회해야 한다.
