## A. 지도·좌표

### Q154. 위치가 리·읍·면 단위로만 알려진 공사 중 정거장 22곳의 좌표는?

- 배경:
  - 공사 중 정거장 156곳 중 29곳은 지도에 나오지 않는다.
  - 고시 지번 또는 "○○동 일원"이 있는 역에는 지번 좌표나 법정동 대표점을 넣었다.
  - 아래 22곳은 리·읍·면 단위로만 알려져 있다.
    - 무안공항(망운면 피서리), 신월(진례면 신월리)
    - 춘천~속초 화천·양구·인제·백담(리)
    - 대구산업선 정거장1·4~8(읍·면)
    - 동해북부선 주문진·양양·간성·제진(읍·면)
    - 월정리(철원읍)
    - 남부내륙 성주·합천·고성·통영(리)·정거장5 거제(면)
  - VWorld 검색 API 는 리 대표점을 주지 않는다. 지오코더에 리 이름만 넣으면 "1번지" 좌표가 나와 쓰지 않았다.
  - 읍·면 대표점은 실제 위치와 수 km 어긋날 수 있다.
- 선택지:
  - A. 비워 둔다(지도에서 빠짐, 현행).
  - B. 읍·면 대표점도 근사 좌표로 넣는다(회색 표시, "수 km 오차" 안내).
  - C. 실시계획 고시의 토지조서·정거장 결정조서에서 지번을 찾아 고시 지번 좌표로 넣는다(조사 작업).
- 임시 가정: A. C 는 실시계획 고시 원문을 확보하는 대로 진행한다.
- 답변: C + 근사 좌표는 지도에 그려지는 노선 선형 위로 옮긴다(2026-10-14). — "고시 지번을 조사하고, 근사하더라도 지도 위에 그려지는 노선도 위로 근사하자."
  - 보충(2026-10-14): "OSM에서 얻은 좌표도 활용하자. 저장하는 것이 아니라 참고하는거잖아." → 선형 위로 옮기는 기준에 OSM 선형을 쓴다. 옮긴 좌표는 지도 산출물에만 있고 data/own·data/build 에 저장하지 않는다.

### Q156. 고시 "노선번호"(예: 경전선 진해선 30701)를 노선 데이터에 넣는가?

- 배경:
  - 국토교통부고시 제2019-173호(사업용철도 노선번호)는 모든 사업용 철도 노선에 5자리 노선번호를 매긴다.
    - 예: 경전선 진해선 30701, 경부선 가야선 30212.
  - 지금은 화물 지선 9개의 노선 설명(note)에만 적었다.
  - 노선번호를 데이터 필드로 두면 고시·철도거리표와 기계적으로 대조할 수 있다. 장래 수집기 gazette-watch 가 노선 신설·변경 고시를 노선에 연결할 때도 쓸 수 있다.
- 선택지:
  - A. note 에만 적는다(현행).
  - B. `codes.molit_line_no` 필드로 두고 화물 지선 9개만 채운다.
  - C. B + 2019-173호 고시 표 전체를 받아 모든 일반철도 노선에 채운다(조사 작업, 고시 원문 PDF 25~27쪽).
- 임시 가정: A
- 답변: C. `codes.molit_line_no` 필드 + 고시 표 전체로 모든 일반철도 노선에 채운다(2026-10-14)
