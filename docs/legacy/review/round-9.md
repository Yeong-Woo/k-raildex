## D. 운영·배포

### Q165. Cloudflare 요금제를 올릴까(접속점 지연)?

- 배경: 서버에서 k-raildex.com 은 LAX 접속점(왕복 0.13초)을 타고, 같은 서버에서 speed.cloudflare.com 은 서울 ICN 39MB/s 다. 무료 요금제 존의 IP 대역이 한국 통신사에서 해외로 라우팅되는 알려진 현상이며 Pro(월 20~25달러)로 올리면 ICN/NRT 를 받는 경우가 많지만 보장은 없다. 비상업 원칙(광고·유료 기능 금지)은 지출 자체를 막지는 않는다. 서버 쪽 조치(gzip·판 태그 캐시·좌표 5자리)는 끝났고 Cache Rule 은 운영자 등록 대기.
- 선택지: A. 무료 유지(이용자 접속점 확인 뒤 재검토) / B. Pro 로 한 달 시험 후 판단 / C. 터널 대신 국내 VPS 리버스 프록시(비용·관리 증가)
- 임시 가정: A.
